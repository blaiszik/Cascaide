# PREEMPTABLE-queue sweep — for runs that DON'T fit debug-scaling's 1 h cap:
# the full 0-300 keV dataset (~7.1k cascades, big high-energy clouds) + a fully-converged
# larger model. 4 cells -> 1 node (4x A100). Submit with the preemptable queue + long walltime:
#
#   QUEUE=preemptable WALLTIME=08:00:00 ./deploy/polaris/submit.sh sweep deploy/polaris/experiments_preempt.txt
#
# PREEMPTION: preemptable jobs can be killed any time and we do NOT auto-resume. --ckpt_every 100
# writes a rolling CONVERGED latest.pt to Eagle every 100 epochs (atomic), so a preempt loses at
# most ~100 epochs and ALWAYS leaves a converged checkpoint to rescore offline — do NOT rely on
# best_by_scorecard.pt (noisy n=6 selection; see job 7183204: bests locked at ep 59/89/329/119
# despite training to ~ep560). Recover/verdict: globus.sh pull-ckpts -> rescore latest.pt locally.
# MEMORY: full range has up to ~1100-defect clouds (O(N^2) attn). --max_defects 1000 (drops 1)
# + batch<=16 is safe on a 40 GB A100; the 512/10 cell drops to batch 8 for headroom.
# WALLTIME: watch ep-1 s/ep in cascaide-sweep.o<jobid>; the 512/10 cell is the long pole.
# Uses --lr_sched cosine; swap in the Experiment-1 winner once known.
# ===========================================================================================
# NOTE: keep experiment lines free of trailing #-comments — gpu_worker.sh passes the line
# verbatim to python, so inline comments would become bad args. Describe cells ABOVE them.
#
